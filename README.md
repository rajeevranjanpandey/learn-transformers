# learnTransformer

> **Transformer, Block by Block** — An interactive visual walkthrough of the Transformer architecture, from zero to GPT and BERT.

Live Website: [https://rajeevranjanpandey.github.io/learnTransformer/](https://rajeevranjanpandey.github.io/learnTransformer/)

## Features
- **Visual & Interactive**: Follow tensor shapes, Q/K/V projections, self-attention, cross-attention, residual connections, and layer norms step-by-step.
- **Math & Intuition**: Real numerical walkthroughs computed directly in the browser alongside high-level intuition and classroom analogies.
- **Self-contained**: Single-page web application with interactive controls, dark/light theme, and printable worksheets.
